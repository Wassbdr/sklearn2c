# Comment mettre sur GitHub

## 1. Initialiser le repo

```bash
git init
git add .
git commit -m "Initial commit - sklearn to C transpiler"
```

## 2. Créer le repo sur GitHub

Va sur github.com et crée un nouveau repo (par exemple `sklearn2c`)

## 3. Pousser le code

```bash
git remote add origin https://github.com/TON_USERNAME/sklearn2c.git
git branch -M main
git push -u origin main
```

## 4. Lien du repo

Ton lien sera :
```
https://github.com/TON_USERNAME/sklearn2c
```

## Fichiers à ne pas oublier

- ✅ README.md (déjà créé)
- ✅ LICENSE (MIT, déjà créé)
- ✅ .gitignore (déjà créé)
- ✅ Les scripts Python
- ✅ Les datasets CSV
